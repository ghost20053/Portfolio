## Editing

- Edit the homepage in `index.html`.
- Edit project content in `data/projects.json`.
- Edit the shared project-page template in `scripts/build-projects.mjs`.
- Run `node scripts/build-projects.mjs` to regenerate `projects/*.html`.
- Run `node scripts/check-site.mjs` before reviewing or committing.
- Keep the generated HTML in Git so hosting does not require Node.

The project pages reuse the homepage header and versioned CSS/JavaScript links.
After changing an asset version in the homepage, regenerate the project pages.
